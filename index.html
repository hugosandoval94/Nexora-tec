02 / MICRO:BIT

Pequeña placa.
Grandes posibilidades.

Nombre del proyecto

Micro:bit – Sistema interactivo con matriz LED

¿Qué es?

micro:bit es una pequeña placa electrónica educativa diseñada para aprender programación, electrónica y creación de proyectos interactivos.

¿Para qué sirve?

Permite trabajar con botones, sensores, LEDs y otros componentes para crear prototipos y automatizaciones.

Problema o necesidad

Se necesitaba crear un sistema sencillo que permitiera aprender cómo funcionan las entradas, el código y las salidas electrónicas.

¿Por qué se creó?

Se creó para practicar programación y electrónica mediante una placa fácil de utilizar y con resultados visibles.

Dificultades encontradas

Comprender la programación de la placa, controlar correctamente la matriz LED y conectar y probar los componentes.

Conclusiones

El proyecto permitió comprender la relación entre programación y electrónica, además de desarrollar habilidades para crear sistemas interactivos.

04 / ROBÓTICA

Seguir una línea.
Tomar decisiones.

FOTO REAL · PROYECTO 03

Nombre del proyecto

Robot seguidor de línea – Robot autónomo

¿Qué es?

Es un robot que utiliza sensores para detectar una línea y ajustar sus motores para seguirla automáticamente.

¿Para qué sirve?

Es una práctica de robótica, sensores, programación y sistemas autónomos.

Problema o necesidad

Se buscaba crear un robot capaz de desplazarse por una ruta sin necesitar que una persona controlara directamente su movimiento.

¿Por qué se creó?

Se creó para aplicar sensores, programación y motores en un sistema capaz de tomar decisiones automáticamente.

Dificultades encontradas

Ajustar los sensores, conseguir que el robot siguiera correctamente la línea y regular la velocidad de los motores.

Conclusiones

El proyecto permitió comprender cómo los sensores y la programación pueden trabajar juntos para controlar un robot de manera autónoma.

05 / MECANISMOS

Una cinta hecha con LEGO.
Una idea industrial.

Nombre del proyecto

Cinta transportadora LEGO – Sistema de automatización

¿Qué es?

Una cinta transportadora mueve objetos de forma continua entre diferentes puntos.

¿Cómo funciona?

Un motor genera movimiento y los mecanismos lo transmiten a la banda, permitiendo transportar objetos.

Problema o necesidad

Se necesitaba representar cómo se pueden transportar objetos de un punto a otro sin hacerlo manualmente.

¿Por qué se creó?

Se creó para demostrar de forma sencilla el funcionamiento de un sistema de transporte automatizado.

Dificultades encontradas

Construir correctamente la estructura, lograr que la banda se moviera de forma continua y ajustar el motor y los mecanismos.

Conclusiones

El proyecto permitió comprender cómo los motores y mecanismos pueden combinarse para automatizar el transporte de objetos.

Nombre del proyecto

Robot con pinzas – Sistema de manipulación

¿Qué es?

Es un sistema robótico equipado con un mecanismo de agarre para sujetar y mover objetos.

¿Para qué sirve?

Se relaciona con automatización, ensamblaje, clasificación y manipulación de objetos.

Problema o necesidad

Se necesitaba crear un mecanismo capaz de sujetar y mover objetos de manera controlada.

¿Por qué se creó?

Se creó para representar el funcionamiento de los brazos robóticos utilizados en procesos de automatización.

Dificultades encontradas

Controlar el movimiento del brazo, ajustar la apertura y cierre de la pinza y conseguir un agarre adecuado de los objetos.

Conclusiones

El proyecto permitió comprender cómo un sistema robótico puede controlar movimientos y manipular objetos mediante diferentes mecanismos.

08 / ROBÓTICA AUTÓNOMA

Robot esquiva obstáculos

Robot construido con micro:bit y ruedas independientes, presentado en la Feria de Tecnología. Su tarea es recorrer una pista llena de conos sin chocar, tomando la decisión de girar hacia un lado u otro según lo que detecta en su camino.

A diferencia del seguidor de línea (que sigue una ruta marcada), este robot debe reaccionar a obstáculos que no siguen un patrón fijo, lo que lo obliga a tomar decisiones en cada tramo del recorrido.

SENSORES DE PROXIMIDAD

Detectan la distancia a los conos cercanos

MOTORES DC

Controlan el giro independiente de cada rueda

PLACA MICRO:BIT

Procesa las lecturas y decide la maniobra a seguir

CHASIS CON RUEDAS

Estructura que soporta el recorrido entre los conos
